# تطبيق الإدارة التربوية المغربية

تطبيق Windows محلي لتدبير الإدارة التربوية بالمؤسسات الابتدائية. يعمل دون إنترنت، ومؤسسة واحدة في كل تثبيت.

## الحالة
| المرحلة | الحالة |
|---|---|
| 0. الأساس (القاعدة، الترحيل، النسخ الاحتياطي) | مبرمجة، مختبرة آلياً |
| 1 إلى 9 | مخطط لها |

## البنية
```
idara/data/       القاعدة، الترحيل، مجلد البيانات، سجل العمليات
idara/services/   منطق العمل
idara/ui/         الواجهة (PySide6)
tests/            اختبارات آلية ببيانات وهمية فقط
```

## حماية البيانات
لا تُرفع إلى هذا المستودع أي بيانات حقيقية: لا قواعد بيانات، ولا لوائح مسار، ولا نسخ احتياطية (انظر `.gitignore`).

## الاختبارات
```
python -m pip install -r requirements-dev.txt
python -m pytest
```
تُشغَّل آلياً على Windows عند كل رفع.
